| 7 | M.C.D. (Euclides) | Ejercicio07 |
| 8 | Copiar cadena | Ejercicio08 |
| 9 | Cociente (restas sucesivas) | Ejercicio09 |
| 10 | Multiplicación (sumas sucesivas) | Ejercicio10 |
| 11 | Suma de arreglo | Ejercicio11 |
| 12 | Suma de matriz m x n | Ejercicio12 |
| 13 | Fibonacci hasta el límite | Ejercicio13 |
| 14 | Función de Ackermann | Ejercicio14 |

Ejecutar: abrir `src/Main.java` en VS Code y pulsar "Run" (requiere JDK 17+ y el
Extension Pack for Java).
